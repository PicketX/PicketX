# HTTP 决策审计页面

以当前具有audit:read权限的身份登录，打开“审计 → HTTP 决策”。读取既有真实
/console/api/v1/http-decisions，仅只读，不要求编辑/发布配置的权限；发布历史
保留为另一审计子视图。

按事件ID从最早开始，每批50条；“读取下一批决策”使用上次成功游标，“从最早
事件重新读取”仅在成功后重置。末尾空页不清除旧记录。最多保留最后加载的200条，
明确标注窗口与游标，不冒充总数、完整历史或自动实时尾随。再次读取可检查新记录，
隐藏页面不读取，不自动轮询。

记录包含ID/时间、允许/拒绝、原因、路由/可信调用方、来源IP、修订与贡献的Grant/
拒绝ID；双栈与长ID换行。决策不证明转发、应用送达或当前权限；来源IP不代表人员。
不将未持久保存的期限/缓存字段写成历史事实；无效/未鉴权调用可能在记录决策前
失败。不展示URI、查询、请求头、正文或凭据。

同一时间仅展开一条记录；Grant/拒绝列表分别每页50个ID，标明位置/总数、前后翻页，
全部已接受ID仍可访问。收起不渲染ID列表，时钟更新不会重建账本。

加载、初次空、末尾空、读取失败、权限丢失、过时均分开显示。失败/异常结构/202
保留旧记录和游标，不用样例或静默前移。401清空并退出，403清空并可重试。60秒后
标为可能落后，包含读取延迟与浏览器/设备休眠时间；它是记录集合的新鲜度，不是
权限租约。请求串行，切换子视图/身份/退出会中止旧请求。

沿用中英、现有浅色/shadcn、键盘焦点、减少动画和375/768/1440布局。严格校验安全
整数、递增/重复/一致性、额外字段、布尔/时间；字符串最多256字符、贡献ID数组最多
4096且不重复。这是展示安全上限，不是授权上限；超限明确报错，不修改权限。
服务端筛选/最新页搜索/导出及保留容量保证留待后续。

允许/拒绝/IPv6/贡献ID；额外205次真实鉴权决策调用仅用于分页/窗口，不冒充205次
转发。503/202/结构/403/能力投影仅为明确标注的UI故障测试；独立凭据真实移除验证
