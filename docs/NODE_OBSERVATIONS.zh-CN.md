# 节点观测

节点页面及 Bearer GET `/api/v1/agent-observations`、SCS Cookie GET
`/console/api/v1/agent-observations` 要求当前 `publication:read` 权限。
响应禁止缓存，拒绝查询参数，不返回任何凭据。

列表仅含当前具有凭据的 Agent 作用域，去重并排序；不是注册管理或所有声明
Agent 的清单。空列表表示无凭据作用域，不代表部署成功。

分别展示已下发期望版本/哈希、当前流连接及最新 Agent 声明（已接收/已应用/失败）。
版本以十进制字符串表示，避免 JavaScript 大整数精度丢失。报告的观察时间由
Agent 提供，接收时间由 Controller 测量。仅同一报告流仍活跃且本地接收后
严格少于60秒，报告才是新鲜的；`matches_desired` 独立比对版本和哈希。
新发布或重连不刷新旧报告。APPLIED 只表示 Agent 报告已应用，不是独立内核证明；
即使新鲜且版本匹配，也不是当前可达性、撤销完成或持续健康保证。目前无心跳协议。

页面进入立即读取，每15秒无重叠轮询；隐藏页暂停、恢复可见时请求刷新、退出取消请求。
若恢复可见时旧请求仍在途，先完成旧请求，下一次轮询再刷新；立即排队补读仍是已记录的小项。
支持手动刷新。失败时保留但明确标记历史数据，不因刷新页面而延长报告有效期。
哈希可展开，移动端卡片换行。

观测仅在进程内，Controller 重启后清空；撤销凭据作用域后从列表消失。
就绪/下发失败返回503，不把旧下发视图伪装为当前状态。本段无历史状态数据库、
多 Controller 汇总、自动 Agent 注册或内核变更；来源权限、绝对期限、LKG和
既有 Agent 执行语义不变。真实当前网络/内核行为仍需特权 Linux 验收。

验证及精确 PR/main 证据见[交付检查点](AUTONOMOUS_DELIVERY.zh-CN.md)。
