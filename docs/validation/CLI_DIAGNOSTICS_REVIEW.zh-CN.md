1. Cobra 在 RunE 前回显非法 duration、未知 flag、额外位置参数。两命令六项
   泄漏回归先失败，再由固定 flag 错误及不回显参数校验转绿。安装/systemd

   Controller 接受含3 MiB `<` 注释且未做HTML转义的请求，输出超过16 MiB；
   诊断回归失败。两个解码字段超限回归也先失败。上限现由两个
   configuration.MaxBytes、最坏六倍转义及4096字节封套推导；前后两次读取
   均校验解码字段上限，超大流仍失败且无输出。不放宽生产者或鉴权/新鲜度。

## 逐项范围裁决及判断错误的代价

| 范围 | 裁决 | 错误代价 |
| --- | --- | --- |
| 原子/持续健康、采样后变化或stdout阻塞 | 仅时间点观察，不作持续租约/修复保证 | 误报后续健康 |
| 恶意父目录替换、文件/CA读取阻塞 | 要求可信父目录；HTTP期限从有界普通文件初始化后开始 | 凭据竞争或初始化延迟 |
| 丢弃的Agent observed_at语法/控制字符 | 不扩大为完整生产者schema审计；不输出、不作时钟 | 接受无效但被丢弃的时间字符串 |
| 超过128字节的时间精度 | 保留明确兼容上限，正常RFC3339Nano输出更短 | 拒绝病态但可解析报告 |
| 独立内核/包验证及部署HTTPS互通 | CLI不能证明；保留协议TLS与独立Linux/应用证据边界 | 夸大执行或拓扑支持 |
| 精确源码原生CI、环境失败及实际包 | 根执行者核验；本地Unix EPERM和孤立慢流通过不能替代完整CI | 未测或过时发布 |
| 穷尽代理环境、坏PEM、大集群压力 | 已检视Proxy=nil/正常CA验证/有界节点；不声明容量认证 | 未覆盖边界或规模限制 |
