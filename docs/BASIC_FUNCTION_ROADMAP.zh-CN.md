## 基本完成的判定

- 四层：真实 TCP/UDP IP/CIDR 准入，IPv4/IPv6，重叠独立 Grant、显式拒绝优先、绝对期限、所选 graceful/strict 行为及所有权范围内的精确清理；HTTPS 与 SSH 权限保持独立。
- 七层：通过可信入口实际执行 HTTP/HTTPS 鉴权；按需使用与请求绑定的已验证身份；资源/方法/路径决策有效；超时、失败、缓存有明确边界；本地决策接口访问受限。要求两层的资源必须两层均允许。
- 管理：管理员可配置支持的资源/部署，查看期望与已确认实施状态及新鲜度，审批/拒绝申请、撤销权限并追溯决策；申请人可登录并理解权限与到期。页面依赖真实后端结果。
- 运维：单节点 Controller/SQLite + Agent 部署有说明，持久保存绝对期限和 provider 身份，有恢复/失败验证、基本授权记录、可运行静态模式及已验证发布产物。

沿用已定首版范围：现有入口负责 TLS 与转发。NFQUEUE 检查、镜像响应、透明代理、数据库原生协议代理、WASM、HA 及大规模容量承诺留待后续。夹具通过不等于生产主机/容器支持；每种实际拓扑均须明确范围并验证。
