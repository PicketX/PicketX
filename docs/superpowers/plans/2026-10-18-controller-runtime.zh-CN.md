# 可运行 Controller 实施计划

使用 executing-plans 内联执行，沿用自动开发与合并授权；完整分支最后独立评审。设计以对应中英M2D2文档为准。

任务1：严格Koanf配置、复用facts解码、GORM/SQLite显式迁移与持久完整发布、共享分发预检。先测覆盖顺序/拒绝非法配置、重启/无变化不增版、私有文件、authority/损坏/未来迁移/CAS/溢出及预检失败不提交，再实现并执行全量测试，提交。

任务2：真实Controller进程和串行重载、凭据与策略分离、readiness、集中监听/关闭/失败回收。先测TCP快照/重启、坏策略保留旧发布、坏策略期间撤销、后注册非空目标、监听失败与取消、TLS错误及持久提交后分发失败，再实现。全量Go/race/vet/build、Web、协议生成及真正静态SQLite二进制启动/探测/停止通过，独立评审后推送/合并/复核main CI，更新检查点并释放租约。
