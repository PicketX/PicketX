# Running Controller publication (M2D2)

## Intent and scope
Make M2D1 usable by the actual Controller entry point with durable authoritative publication and lifecycle. This is the next dependency of Agent Controller Mode and real administration/L7. It does not claim remote kernel execution or management completion. The user explicitly requests autonomous development/merging to those outcomes; execute this reviewed design inline without approval menus.

## Runtime configuration
Use selected Koanf v2.3.8 at assembly, with explicit changed flags > present PICKETX_* environment > strict YAML file > defaults. Existing -listen remains an explicit HTTP override; add -config and -agent-listen. Default behavior remains liveness-only HTTP127.0.0.1:8080, Agent disabled. With Agent enabled require fixed authority, policy/facts paths, private SQLite database path, credential file, positive poll/shutdown/stream limits and valid listen addresses. Defaults: Agent127.0.0.1:9090, poll1s, shutdown5s, maxCredentials128/maxStreams128/maxFrame4MiB/establish128/messages32/Hello5s/send10s. Expose all supported settings; reject unknown fields, null, duplicate/multi-document YAML and invalid values before effects. Runtime file/environment secrets are never merged into desired policy. TLS cert/key both configured or neither; standard server TLS >=1.2, no mTLS requirement. Plaintext remains explicit allowed configuration and exposes bearer credentials on that hop.

## Durable publication
Use selected GORM1.31.2 + official SQLite1.6.0 + mattn1.14.52; no invented database adapter. One private local DB, one current full accepted policy/facts record, a versioned explicit migration (not AutoMigrate) and revision CAS. SQLite synchronous FULL, DELETE journal, bounded busy wait and one connection. Bound files/records at4MiB, preserve original policy and strict facts, verify an envelope integrity digest on recovery. Identity is fixed; reject DB authority mismatch, corrupt records and unknown newer migration. Positive revision is signed SQLite integer, refuses overflow. No semantic change means no revision bump. Compilation/Replace and service publication preflight happen before durable commit; commit precedes in-memory distribution. The runtime owns credential mutation/publication and serializes them, so after a successful preflight the same prepared state is publishable; unexpected distribution error is fatal and recovered from DB on restart. Cross-process CAS rejects concurrent stale publication; no HA or cross-process cache coherence claim.

A recovered accepted record can serve during a bad current file reload. First startup without any accepted publication requires valid input. Invalid policy/facts/credentials reload leaves previous accepted state and current stream credentials intact and sets readiness false; a later valid full source recovers readiness. Credential updates never bypass M2D1 atomic validation, revocation, scoping or byte limits. Changed credentials apply independently even when policy is invalid, allowing revocation during publication failure. No deadlines are regenerated. Never log raw credentials or SQL payloads. No unauthenticated management/state API in this slice.

## Lifecycle
Inject typed config, logger and listener factory at assembly. Reserve configured listeners, initialize database/credentials/publication, then serve HTTP/gRPC. Startup failure closes every reserved listener, DB and service. GET/HEAD healthz remains liveness; readyz reports aggregate runtime readiness only, no policy/credential details. Polling is context-cancellable and bounded; Close terminates streams, HTTP shutdown and gRPC graceful shutdown have finite deadlines then forced stop. Stop the publisher before closing the service/store. Fixed HTTP read/header/write/idle bounds and gRPC4MiB message bounds remain. Emit structured actual listen addresses to support ephemeral ports and artifact smoke tests.

## Verification and release
Tests must cover config precedence/unknown/null/duplicates, original HTTP default, schema migration/newer version, private DB/restart/CAS/integrity/authority/overflow, invalid reload retaining LKG, independent credential revocation during bad policy, fresh nonempty credential enrollment, normal TLS setup errors, listener rollback/cancellation, real TCP gRPC snapshot/report and readiness. Extract existing exact strict facts decoder into configuration and retain all CLI regressions.

Run complete Go/race/vet/build, Web lockfile checks and pinned protocol generation. A new default static Linux Controller artifact uses CGO static linking with netgo/osusergo/sqlite_omit_load_extension; inspect ELF/ldd and actually launch it with SQLite/Agent listener, probe readiness, verify the persisted revision and stop it with SIGTERM. CI runs the same artifact smoke. Do not claim PostgreSQL/production Agent integration from these tests.
