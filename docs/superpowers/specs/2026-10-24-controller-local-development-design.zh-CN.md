# Controller 首次启动与本地开发

[English](2026-10-24-controller-local-development-design.md) | 简体中文

状态：用户于2026-10-24批准的新方向，替代之前的开发 CLI/初始化工具方案。

## 决定

Controller **未指定配置文件的正常启动**使用完整单实例 SQLite 配置，创建数据库管理员 `admin`，生成随机密码并写入私有本地文件。这是开发和部署共用的首次启动行为，不是特殊开发模式。显式配置保留既有默认值及信任契约，兼容文件权威及预配置部署。

Go/Web 独立运行，Vite 保留常规8080代理并严格固定5173。IDE 直接运行普通 Go 入口，无需设置 Origin。不保留开发 CLI、准备脚本、doctor、生成配置、新依赖、进程管理器或专用开发 E2E 套件。

## 启动契约

- 无配置文件：完整后端，HTTP8080、Agent gRPC9090、决策9091，数据库配置/账户权威，默认不绑定浏览器 Origin；静态资源由现有配置显式启用。
- 私有状态默认 `var/controller/`，数据库 `controller.sqlite`；复用已有版本迁移和管理发布引导。
- 创建新的默认数据库前，准备私有管理恢复凭据、空 Agent/调用方文件及 `initial-admin-password`。保留现有恢复密钥要求，独立原始恢复密钥写入 `initial-recovery-key`。
- 文件0600，父目录0700；只记录用户名及文件路径，不输出密码、密钥或摘要。拒绝不安全已有文件，不覆盖、不自动轮换。
- 仅身份目录 revision 为零时，验证初始恢复密钥与实际管理凭据匹配且有账户写权限，再使用现有账户保存/哈希/审计流程创建 `admin`。非零 revision 永久表示已初始化，禁用账户或删除密码文件不得重新创建管理员。
- 先持久化初始密码再创建账户；中断后复用待完成的私有密码继续。已有数据库不触发缺失凭据文件或密码的重新生成。
- 显式配置保留原行为，不自动切换已部署数据库的配置/账户权威。环境/参数优先级及未知键拒绝不变。
- 空 Agent/调用方不认证任何人；PicketXD/Nginx 不是前置条件，就绪不代表执行成功。

## 开发与构建 Web

后端：`go run ./cmd/picketx-controller`；Web：现有 `npm ci` / `npm run dev`。选择密码登录，使用 `admin` 和私有密码文件。IDE 直接运行后端，无需 Origin 环境变量。

构建 Web 后使用现有 `PICKETX_BROWSER_ASSETS=web/dist`，后端使用普通8080监听，复用数据库和凭据。重启只使会话失效，不改变人员或密码；保留当前 HTTP/浏览器超时。

## 验证与范围

测试首次登录/账户审计、重启稳定、已修改/禁用管理员不变、密码/凭据文件缺失、私有权限及日志不泄密。使用一次性本地 smoke 验证真实 SQLite/HTTP/gRPC 和 Vite 代理密码登录。复用现有 Go/Web 检查，不引入平台发布机制或开发测试框架。

实现限定为简短正常启动默认配置加载、复用账户 API 的聚焦运行引导及其边界测试、已有 Vite/IDE 配置和简洁双语文档。

## 2026-10-25 修订：可选公开 Origin

用户同意平衡易用性与基本请求保护。`browser.origin` 默认空：不绑定固定 Host/端口，写请求与实际请求 Host 和 HTTP/TLS scheme 同源；显式设置时保留准确 Host/Origin 校验。不推断转发头；HTTPS 终止及 OIDC 使用明确公开地址。Cookie Secure 根据配置 HTTPS 或真实 TLS 决定，不修改共享会话/中间件状态。CSRF/会话/RBAC 保留。本地 Go/Vite 默认启动无需 Origin 环境变量。

保留现有显式登录方式选择。能力读取失败时展示错误与重试，不显示误导性的仅密钥认证界面。
